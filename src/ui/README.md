# Компоненты интерфейса CRM

Компоненты, стили, шрифты и механизмы focus/resize перенесены из Base PDLC
0.3.33, commit `5b6a3f3b0e538c9e6eb0ed0a7f455dca05bf67de`, по поручению
владельца. Это обычные исходники mini-crm; дальнейшие изменения выполняются здесь.

Сохранены необходимые компоненты и их транзитивные зависимости. Из оболочки,
меню и диалогов удалены подключения к каталогу сервисов, управляемому брендингу,
namespace-навигации и host-readiness PDLC. Заголовок использует локальный AppHeader,
тема хранится в предпочтениях mini-crm. Radix сохраняет управление focus,
клавиатурой, модальностью и доступностью диалогов и меню.

В `styles/tokens.css` оставлены общие tokens и правила используемых компонентов;
шрифты обрабатывает Vite. Их лицензии и происхождение находятся
в `public/licenses/fonts/`. Исходные условия Base сохранены в LICENSE и NOTICE
этого каталога. Зависимость от пакета и подготовка внешнего UI-архива удалены.
