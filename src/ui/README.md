# Компоненты интерфейса

Локальные компоненты, стили и шрифты основаны на Base PDLC 0.3.33,
commit `5b6a3f3b0e538c9e6eb0ed0a7f455dca05bf67de`.
Они развиваются в этом репозитории без зависимости от внешнего UI-пакета.

Используются Radix для диалогов и меню, Tailwind CSS и общие дизайн-токены.
AppHeader, навигация и хранение темы адаптированы к CRM. Неиспользуемые шаблоны
страниц и строки платформенных сервисов исключены.

- `components/` — элементы управления, формы, навигация и отображение данных.
- `lib/` — тема, focus/resize и утилиты оформления.
- `styles/` — токены, стили компонентов и шрифты.
- `i18n/` — подписи интерфейса.

Исходные условия Base сохранены в [LICENSE](LICENSE) и [NOTICE](NOTICE).
Происхождение и лицензии шрифтов находятся в [public/licenses/fonts](../../public/licenses/fonts/).
