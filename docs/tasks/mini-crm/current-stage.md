# Обзор реализации

Мини-CRM реализует управление строительными объектами и задачами с двумя ролями,
защищёнными переходами статусов и историей изменений.

## Реализовано

- Вход, два вида доступа и пять основных экранов.
- Объекты и задачи: создание, редактирование, переназначение и мягкое удаление.
- Выполнение, проверка, доработка и приёмка с общей историей.
- Проверки прав и переходов в PostgreSQL, независимо от интерфейса.
- Формы с валидацией и сохранением ввода при ошибке, поддержка клавиатуры.
- Мобильная навигация, читаемые таблицы и три темы оформления.

## Проверки

| Уровень            | Набор                                                                |
| ------------------ | -------------------------------------------------------------------- |
| Типизация и сборка | TypeScript, Vite                                                     |
| Модульные проверки | 8 тестов: матрица действий и согласованность кэша                    |
| API и база         | 10 групп: изоляция, переходы, история и конкурентные запросы         |
| Инфраструктура     | Блокировки, пароли ролей DB, доверенный IP и раздельные лимиты Nginx |
| Браузер            | 12 сценариев × desktop/mobile = 24 проверок Chromium                 |

Браузерные сценарии используют настоящий API. Ошибки и задержки транспорта
моделируются только в проверках сетевых сбоев. Подробности и воспроизведение —
в [матрице тестирования](test-cases.md).

## Ограничения

Текущий стенд использует временный публичный адрес. Реальные мобильные устройства,
другие браузеры, нагрузка, резервирование и мониторинг отдельно не квалифицированы.
Функции за пределами реализованного объёма перечислены в [решениях](../../decisions.md).
