# Требования

CRM для строительных объектов: постановщик назначает работы, исполнитель выполняет
и сдаёт результат на проверку. Стек — React, TypeScript и Supabase.

## Данные и инварианты

| Сущность | Данные                                                       | Владелец правила                                                                       |
| -------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------- |
| Профиль  | UUID пользователя Auth, имя, роль                            | Администратор; клиент не назначает себе роль                                           |
| Объект   | Название, адрес; служебные UUID, дата, признак удаления      | Постановщик; база проверяет запись и доступ                                            |
| Задача   | Название, описание, объект, исполнитель, статус, автор, дата | Постановщик редактирует обычные поля; база назначает авторство/дату и проверяет статус |
| История  | Задача, участник, из/в статус, комментарий, время            | Только триггер/RPC в базе; браузер читает                                              |

Смена статуса и добавление истории — одна транзакция с блокировкой строки задачи.
При конфликте возвращается HTTP 409. Принятая задача не открывается заново.
Конкретная таблица переходов и пользовательская последовательность принадлежат
[workflow](../../workflow.md); допущения — [decisions](../../decisions.md).

## Допущения и границы

- Одна компания, общий контур постановщиков; разделение по организациям не входит.
- Описание задачи необязательно; объект и исполнитель обязательны.
- Переназначение сохраняет статус/историю, переносит видимость новому исполнителю.
- Удаление мягкое; восстановление из UI не входит в ТЗ.
- Администрирование пользователей, восстановление пароля по почте, уведомления,
  вложения, сроки, поиск по задачам и журнал обычного редактирования не входят.
- Постоянный домен, резервное копирование, мониторинг и эксплуатационные гарантии
  не выдаются за реализованные части тестового стенда.
